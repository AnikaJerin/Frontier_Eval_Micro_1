# Data sources, permissions and limitations

I've used Ogimet (https://www.ogimet.com/) as the source of SYNOP reports, and the NOAA/NWS Aviation Weather Center interface (https://aviationweather.gov/data/metar/?decoded=1&ids=VGHS&hours=96) as the source of METAR and TAF material. The linked interface is a rolling view, not a permanent citation for each historical record. The dataset contains reports from multiple stations; the VGHS query alone does not independently establish provenance for every station or TAF. Individual record-level URLs, retrieval times and licenses were not provided. The original JSONL is preserved unchanged.

WMO/ICAO code documentation and the source-backed task derivations are cited in the reference audits. Their presence does not establish the physical correctness of the observations or independent expert certification.
